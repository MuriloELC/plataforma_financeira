# Project Rules

1. BLUEPRINT.md é a fonte da verdade.
2. Nenhuma implementação sem tarefa em TASKS.md.
3. Nenhuma regra financeira crítica no frontend.
4. Nenhum parser salva direto no Gold.
5. Todo arquivo importado tem hash.
6. Todo lote tem import_batch_id.
7. Todo dado manual tem auditoria.
8. Todo cálculo financeiro tem teste.
9. Dados reais nunca entram no Git.
10. IA só entra depois de Gold confiável.
11. Ambiguidade exige revisão.
