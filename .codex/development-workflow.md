# Development Workflow

1. Escolher tarefa pequena em TASKS.md.
2. Ler BLUEPRINT.md e feature correspondente.
3. Planejar em poucas linhas.
4. Implementar migration se necessário.
5. Implementar models/schemas/services.
6. Implementar endpoint/tela.
7. Criar testes.
8. Rodar validações.
9. Atualizar TASKS.md.
10. Atualizar CHANGELOG.md.
